# f1-retro-reviews

Home of our four-person fantasy league's weekly race review posts, as we replay the 2024 Formula 1 season race by race.

- Each round's review is published as Markdown under [`reviews/`](reviews/) — one file per race (e.g. [`reviews/monza-2024.md`](reviews/monza-2024.md)).
- League picks: Lewis Hamilton, Lando Norris, Charles Leclerc, Oscar Piastri.
- Season prize pot: 2 ETH.
